Spacepad est installé

1. Ouvrez Spacepad depuis le dossier Applications.

2. Cliquez sur « Choisir un dossier… » et sélectionnez le dossier de vos sons. Spacepad l’analyse, puis cliquez sur Enregistrer.

3. Dans Logic Pro, Ableton ou GarageBand, ouvrez le plugin JB Praise : Spacepad (instrument) : vos librairies y sont déjà.

Si macOS refuse d’ouvrir l’application la première fois, faites un clic droit sur « Spacepad », puis Ouvrir.

Pour désinstaller : ouvrez Désinstaller Spacepad dans le dossier Applications.

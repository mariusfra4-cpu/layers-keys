AFRICAN LOOPS PRO - INSTALLATION
================================

WINDOWS
-------
1. Copiez le dossier « African Loops Pro.vst3 » dans :
       C:\Program Files\Common Files\VST3\
2. Ouvrez votre logiciel de musique (FL Studio, Ableton, Cubase, Studio One,
   Reaper...) et lancez une recherche de nouveaux plugins si besoin.
   African Loops Pro apparaît dans les instruments.
3. « African Loops Pro.exe » fonctionne aussi tout seul, sans logiciel de musique.

MAC
---
1. Copiez :
     « African Loops Pro.vst3 »      dans  Bibliothèque/Audio/Plug-Ins/VST3/
     « African Loops Pro.component » dans  Bibliothèque/Audio/Plug-Ins/Components/
     « African Loops Pro.app »       dans  Applications
2. Les fichiers ne sont pas encore signés par Apple : la première fois, faites
   clic droit > Ouvrir sur l'application, ou dans le Terminal :
       xattr -cr ~/Library/Audio/Plug-Ins/VST3/"African Loops Pro.vst3"
       xattr -cr ~/Library/Audio/Plug-Ins/Components/"African Loops Pro.component"
       xattr -cr /Applications/"African Loops Pro.app"

LICENCE
-------
- Au premier lancement, l'écran « Autoriser le logiciel » affiche le code de
  l'ordinateur (JBA-XXXX-XXXX-XXXX-XXXX). Envoyez-le à JB Praise : vous
  recevez une clé de licence. Collez-la et cliquez sur ACTIVER.
- Une clé = un ordinateur. Pas besoin d'Internet. La même clé active la
  version seule et les plugins.
- ESSAYER 3 JOURS : tout le logiciel fonctionne pendant 3 jours (une seule
  fois par ordinateur). Le temps restant est affiché en haut à gauche, avec
  le bouton ACTIVER.

UTILISATION
-----------
- DOSSIER : choisissez le dossier de vos loops (WAV ou MP3). Elles sont toutes
  analysées une seule fois (tempo, percussions) et classées par style :
  le nom du dossier décide (« Worship », « Gospel »...).
  Clic droit sur une loop : la ranger dans un autre style.
  Clic droit sur un style : le renommer, ou le supprimer (ses loops vont
  dans « Non classés », aucun fichier n'est effacé).
- ★ : cliquez sur l'étoile d'une loop pour la mettre dans « ★ Favoris ».
- + STYLE : crée un style (et son dossier). IMPORTER : copie des WAV / MP3
  dans un style. Glissez une loop sur un style pour l'y ranger.
  Clic droit sur un style : renommer, supprimer, importer, ouvrir le dossier.
- + FICHIER, ou glissez un WAV / MP3 sur la fenêtre : ouvre une seule loop.
- Chaque percussion reconnue arrive sur sa piste : volume, pan, M (couper),
  S (écouter seule).
- Attrapez la forme d'onde et déposez-la sur une piste de votre logiciel :
  la boucle est copiée telle que vous l'entendez (tempo, mix).
  Attrapez le numéro « ☰ 1 », « ☰ 2 »... sous un fader : cette piste seule.
- GLOBAL BPM : glissez vers le haut / bas, ou double-cliquez pour taper.
  HOST allumé : suit le tempo et la lecture de votre logiciel de musique.
  PRESET allumé : la loop joue à son tempo d'origine.
- DOUBLE / HALF : deux fois plus vite / deux fois plus lent.
- SIGNATURE : 4/4 joue la loop telle quelle ; 3/4 rejoue chaque mesure en valse
  (temps 1, 2, 3) ; 6/8 lui donne un balancement ternaire.
- En pleine lecture, la loop choisie entre à la PROCHAINE MESURE, sur le
  temps 1 : jamais de décalage.
- LINK (Ableton Link) : Ableton Live et les autres logiciels Link prennent le
  tempo de chaque loop choisie, avec les mêmes barres de mesure ; Play / Stop
  partent ensemble à la mesure suivante. Dans Ableton : activez Link en haut
  à gauche, et dans les Préférences > Link, « Start Stop Sync ».
- ENREGISTRER SETUP (en haut à droite) : garde la loop, le tempo, le mixer et
  tous les effets sous un nom. MES SETUPS : les rappeler, les renommer, les
  supprimer. Fonctionne dans le VST3 et dans la version seule.
- PRO RACK FX : chaque bouton ouvre la page des effets à la place du mixer
  (« RETOUR AU MIXER » ou Échap pour revenir). Bouton allumé = effet actif.
  MASTER FX : égaliseur 4 bandes, compresseur, limiteur.
  SEND FX : réverbération (Studio, Salle, Église, Plaque) et envoi par piste.
  MOD FX : chorus, flanger, phaser, trémolo + écho calé sur le tempo.
  EQ PAR PISTE : graves / médium / aigus de chaque percussion.
  FADE : fondus au départ / à l'arrêt (en mesures) et fondu enchaîné entre
  deux loops.
- ⚙ (en haut à droite) : la langue du logiciel - Français, English, Español,
  Português. Le changement est immédiat et gardé pour la prochaine fois.
- Clavier : Espace = lecture / arrêt ; flèches haut / bas = loop précédente /
  suivante.

# Licences Eli Guitar Chords (sans Internet)

Comme pour Layers Keys : **aucune connexion Internet**, ni pour l'appli, ni pour le générateur.

## Une fois pour toutes

Installe **Eli-Cles-Generateur.apk** sur TON téléphone (jamais chez un client).
Au premier lancement, entre ton mot de passe et laisse « Rester déverrouillé » coché.

## Activer un client

1. Le client installe **Eli-Guitar-Chords.apk** et l'ouvre : l'écran affiche le **code de son
   téléphone** (`ELI-XXXX-XXXX-XXXX-XXXX`). Il te l'envoie avec « Envoyer à Eli Praise ».
2. Dans WhatsApp : appui long sur son message > **Partager** > **Eli Clés**.
   Le code est rempli et la clé est fabriquée. (Ou : copie le message, puis « COLLER » dans Eli Clés.)
3. **ENVOYER AU CLIENT** : il copie la clé, touche **Coller ma clé** (ou la colle) puis **Activer**.

C'est terminé : l'appli est activée pour toujours sur ce téléphone, sans Internet.

- Une clé ne marche que sur le téléphone dont elle porte le code : la partager ne sert à rien.
- Le même code redonne toujours la même clé (pratique si le client la perd).
- Si le client réinitialise son téléphone ou en change, son code change : il t'envoie le nouveau.
- L'historique d'Eli Clés garde chaque client (nom, code, clé, date) ; « ENVOYER L'HISTORIQUE (CSV) »
  en fait une copie.

## Important

- Garde ton mot de passe d'Eli Clés en lieu sûr : sans lui, le générateur ne peut plus être
  déverrouillé sur un nouveau téléphone.
- Comme il n'y a plus d'Internet, une licence donnée ne peut plus être retirée à distance.
